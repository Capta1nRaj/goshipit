# Category O - Agent Readiness (isitagentready.com + Vercel Spec + llmstxt.org v2)

> Merges Cloudflare isitagentready.com (5 categories), agent-ready.dev 71-check methodology, Vercel Agent Readability Spec (S1-S15/P1-P24), llmstxt.org v2, and protocol specs (MCP/A2A/WebMCP/ACP/UCP/x402). All checks are codebase-only (no live fetch) - verify via `public/`/`static/`/`app/` presence, `next.config`/`_headers`/`middleware`, and `Glob`/`Grep`/`Read`. Skip protocol checks marked "only if" when stack not applicable.
>
> **Attribution:** Category O merges 4 independent sources — [Cloudflare's isitagentready.com](https://isitagentready.com) (1 part: 5 categories), [agent-ready.dev](https://agent-ready.dev) (71 checks), [Vercel Agent Readability Spec](https://vercel.com/kb/guide/agent-readability-spec), and [llmstxt.org](https://llmstxt.org) v2 — plus open specs MCP/A2A. Only isitagentready.com is by Cloudflare; others are independent. Not affiliated with or endorsed by Cloudflare or Vercel. Checks implement open standards (RFC 8288, RFC 8615, RFC 9727/9728) in our own words.
